# Bank Customer Churn Dashboard

## Overview
An interactive Excel dashboard built using Pivot Tables, Pivot Charts, KPIs, and Slicers to analyze customer churn and customer behavior.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards

## KPIs
- Total Customers
- Churned Customers
- Active Members
- Churn Rate
- Average Balance
- Customers with Credit Card

## Dashboard Insights
- Churned Customers by Country
- Churn by Gender
- Churn Rate by Age Group
- Churned vs Active Members
- Customers by Tenure
- Balance Group Analysis
